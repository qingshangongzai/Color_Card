# 多语言国际化规范

> 本文为《开发规范.md》拆分出的专项规范，涉及界面文本国际化、语言包维护时阅读。

## 1. 模块概述

多语言国际化功能由 `utils/locale.py` 模块提供，支持应用程序的多语言切换。

**核心组件：**

|           组件           | 说明                       |
| :--------------------: | :----------------------- |
|     `LocaleManager`    | 多语言管理器，负责语言包加载、切换和翻译文本获取 |
|         `tr()`         | 翻译文本获取函数                 |
|    `set_language()`    | 语言切换函数                   |
| `get_locale_manager()` | 获取全局语言管理器实例              |

## 2. 语言包结构

语言包存放在 `locales/` 目录，使用 TOML 格式。

```toml
[app]
name = "取色卡"
name_en = "Color Card"

[navigation]
color_analysis = "色彩分析"
settings = "设置"

[messages.copy_success]
title = "已复制"
content = "颜色值已复制到剪贴板"
```

## 3. 使用方法

**基本翻译：**

```python
from utils import tr
text = tr('navigation.color_analysis')  # 返回 "色彩分析" 或 "Color Analysis"
```

**参数化翻译：**

```python
# 语言包中定义： "content": "颜色值 {value} 已复制到剪贴板"
text = tr('messages.copy_success.content', value='#FF5733')
```

**语言切换：**

```python
from utils import set_language, get_locale_manager

set_language('EN_US')
get_locale_manager().language_changed.connect(self._on_language_changed)
```

## 4. 界面国际化规范

```python
class MyInterface(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        get_locale_manager().language_changed.connect(self._on_language_changed)
    
    def _on_language_changed(self, language_code):
        self.update_texts()
    
    def update_texts(self):
        self.title_label.setText(tr('my_interface.title'))
```

**翻译键命名规范：**

|  模块  | 命名格式                 | 示例                            |
| :---: | :------------------- | :---------------------------- |
| 应用通用 | `app.*`              | `app.name`                    |
|  导航栏 | `navigation.*`       | `navigation.color_analysis`    |
| 界面模块 | `{module}.*`         | `settings.title`              |
| 提示消息 | `messages.*`         | `messages.copy_success.title` |

## 5. 支持的语言

|   语言代码  | 语言名称     |
| :-----: | :------- |
| `HY_JT` | 简体中文（默认） |
| `HY_FT` | 繁體中文     |
| `EN_US` | English  |
| `JA_JP` | 日本語      |
| `FR_FR` | Français |
| `RU_RU` | Русский  |
