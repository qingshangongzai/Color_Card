# 颜色处理规范

> 涉及颜色转换、明度计算、Zone 分区逻辑开发时阅读。

## 1. 颜色空间转换

- 纯颜色转换函数放在 `core/color.py`；需要缓存或 UI 交互的封装放 `core/color_service.py`（`ColorService`）
- 返回结果包含完整的颜色信息

```python
def get_color_info(r, g, b):
    """获取颜色的完整信息"""
    return {
        'rgb': (r, g, b),
        'hsb': (H, S, B),
        'lab': (L, A, B),
        'hex': rgb_to_hex(r, g, b)
    }
```

## 2. 明度计算规范

按 Rec. 709 系数在线性空间加权：`0.2126 R + 0.7152 G + 0.0722 B`；默认按 sRGB Gamma（2.2）编码回 0-255。实现见 `core/color.py::get_luminance()`。

## 3. Zone 分区规范

明度按 9 等分划分（`ZONE_WIDTH = 255 / 9 ≈ 28.33`），共 9 个 Zone；对外显示时归并为 5 个区域名称：

| 区域 | Zone 索引 | 明度范围（0-255） | 占比 | 说明 |
| :-: | :-: | :--: | :--: | :-- |
| 黑色 | 0 | 0-28 | 0-11% | 黑点区域，最暗的部分 |
| 阴影 | 1-2 | 28-85 | 11-33% | 阴影区域，较暗的色调 |
| 中间调 | 3-5 | 85-170 | 33-67% | 中间亮度区域，由 Exposure/Contrast 负责调整 |
| 高光 | 6-7 | 170-226 | 67-89% | 高光区域，较亮的色调 |
| 白色 | 8 | 226-255 | 89-100% | 白点区域，最亮的部分 |

> 实际边界以上表为准；Zone 索引与范围由 `core/color.py` 的 `ZONE_WIDTH`、`get_zone()` 定义。
