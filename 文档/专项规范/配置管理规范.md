# 配置管理规范

> 涉及配置项新增、修改时阅读。

## 1. 配置管理模块

使用 `core/config.py` 统一管理应用程序状态。

- 配置文件：JSON 格式，存储在用户主目录下的 `.color_card/config.json`
- 使用单例模式获取全局配置管理器实例

## 2. 常用配置项

本表非全量，完整默认值由 `core/config.py` 的 `_load_default_config()` 维护；新增配置键时同步补充常用项。

|              配置键              |   类型   |       默认值       | 说明                         |
| :---------------------------: | :----: | :-------------: | :------------------------- |
|     `settings.hex_visible`    |  bool  |       true      | 是否显示16进制颜色值                |
|     `settings.color_modes`    |  list  | \["HSB", "LAB"] | 色卡中显示的色彩模式                 |
| `settings.color_sample_count` |  int  |        5        | 色彩分析采样点数量                  |
|      `settings.language`      | string |      "auto"     | 界面语言（auto=跟随系统，回退简体中文；可选 HY_JT/HY_FT/EN_US/JA_JP/FR_FR/RU_RU） |
|         `window.width`        |  int  |       940        | 窗口宽度（运行时受最小尺寸夹取；尺寸表见《界面与主题规范》§3） |
|        `window.height`        |  int  |       660       | 窗口高度                       |
|     `window.is_maximized`     |  bool  |      false      | 窗口是否最大化                    |
|     `window.is_fullscreen`    |  bool  |      false      | 窗口是否全屏                     |
|          `favorites`          |  list  |       \[]       | 收藏的配色列表                    |

> `window.is_fullscreen` 未在默认配置中预置，由主窗口保存时写入，读取时按 `false` 兜底。

## 3. 使用示例

```python
from core import get_config_manager

config_manager = get_config_manager()
hex_visible = config_manager.get('settings.hex_visible', True)
config_manager.set('settings.hex_visible', False)
config_manager.save()
```
