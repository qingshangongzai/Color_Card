# 界面与主题规范

> 涉及界面布局、主题与样式、颜色管理、Fluent 窗口、无边框对话框、信号同步、自定义控件与菜单时阅读。

> 适用范围：主程序界面（`ui/`、`dialogs/`、`uninstaller/`）。`installer/` 的向导界面不复用组件库与 `utils/theme_colors.py`，不在本规范约束内，豁免口径与同步约束见《开发规范》§3.8。

## 1. 布局原则

- 使用布局管理器（QVBoxLayout, QHBoxLayout）
- 避免使用固定尺寸，优先使用 size policy

## 2. 防止布局重叠

**问题：** 窗口被压缩时组件重叠。**原因：** `minimumSize` 过大、缺少 `sizePolicy`、使用 `setFixedHeight()` 等固定尺寸。

**做法：**

1. 设置合理的 `minimumSize`：`self.setMinimumSize(300, 200)`
2. 用 `sizePolicy` 控制扩展：`self.setSizePolicy(QSizePolicy.Policy.Expanding, QSizePolicy.Policy.Expanding)`
3. 用最小 / 最大高度代替固定高度：`self.color_block.setMinimumHeight(40)`、`setMaximumHeight(80)`

**实践：** 自定义组件必须设置 `sizePolicy`；测试时把窗口压缩到最小尺寸，检查是否重叠。

## 3. 控件尺寸参考

|     控件     |   推荐尺寸   |   紧凑尺寸  | 说明           |

## 4. 网格布局自适应宽度

**问题：** QGridLayout 所有行共享列宽，每行色卡数量不同时无法各自占满整行。

**做法：** 每行列数相同 → 用 QGridLayout；每行列数不同 → 改用垂直布局 + 每行一个水平布局：

```python
self.cards_layout = QVBoxLayout()
columns = self._calculate_columns(len(colors))

current_row_layout = None
for i, color in enumerate(colors):
    if i % columns == 0:
        current_row_layout = QHBoxLayout()
        self.cards_layout.addLayout(current_row_layout)
    current_row_layout.addWidget(ColorCard(), stretch=1)
```

## 5. 主题切换与自适应

- 切换主题用 `setTheme(Theme.LIGHT/DARK)`，判断当前主题用 `isDarkTheme()`，监听变化用 `qconfig.themeChangedFinished`。
- **需要随主题变化的组件必须实现 `_update_styles()`**：在 `__init__` 中先调一次初始化样式，再连接 `themeChangedFinished`；按 `isDarkTheme()` 返回不同颜色。
- `_update_styles()` 只更新必要的文字颜色；不用 `setStyleSheet` 覆盖容器背景、边框等整体样式，主题切换交给 qfluentwidgets 原生机制。

```python
from utils.theme_colors import get_text_color

class MyWidget(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setup_ui()
        self._update_styles()
        qconfig.themeChangedFinished.connect(self._update_styles)

    def _update_styles(self):
        """更新样式以适配主题"""
        self.label.setStyleSheet(f"color: {get_text_color().name()};")
```

## 6. 颜色管理

**禁止在组件中硬编码颜色值**，所有颜色统一由 `utils/theme_colors.py` 提供：

```python
# 正确
from utils.theme_colors import get_text_color
text_color = get_text_color()

# 错误
painter.setPen(QColor(255, 255, 255))
```

**颜色函数按用途分类：**

|   分类  | 函数示例                            | 说明                  |
| :---: | :------------------------------ | :------------------ |
|  背景色  | `get_canvas_background_color()` | 图片显示器背景（固定 #2a2a2a） |
|  背景色  | `get_dialog_bg_color()`         | 对话框背景（主题感知）        |
|  文本色  | `get_text_color()`              | 主文本颜色（主题感知）        |
|  边框色  | `get_border_color()`            | 边框颜色（主题感知）         |
|  控件色  | `get_picker_border_color()`     | 取色点边框颜色            |

**添加新颜色：** 在 `utils/theme_colors.py` 新增函数，选合适的分类，组件中调用该函数。

## 7. Fluent 窗口

- 主窗口继承 `FluentWindow`，用 `addSubInterface` 挂载子界面
- 用 `setThemeColor('#0078d4')` 设置主题色；全局主题用 `setTheme(Theme.AUTO)`

```python
from qfluentwidgets import FluentWindow, FluentIcon, Theme, setTheme, setThemeColor

setTheme(Theme.AUTO)
setThemeColor('#0078d4')

class MainWindow(FluentWindow):
    def setup_navigation(self):
        self.addSubInterface(self.interface, FluentIcon.PALETTE, "界面名称")
```

## 8. 无边框对话框

**基类：** `dialogs/base_frameless_dialog.py` 的 `BaseFramelessDialog`（Fluent 风格标题栏 + 主题适配）。

**必须做到：**

- 调用 `_setup_title_bar()` 设置标题栏，调用 `_update_styles()` 初始化样式
- 布局顶部边距设为 40px，为标题栏留出空间
- 父窗口传顶层窗口：`parent=self.window()`
- `closeEvent` 中调用 `super().closeEvent(event)`，基类会自动断开主题信号

```python
from dialogs import BaseFramelessDialog
from qfluentwidgets import qconfig
from PySide6.QtWidgets import QVBoxLayout

class CustomDialog(BaseFramelessDialog):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setWindowTitle("自定义对话框")
        self.setFixedSize(400, 300)
        self._setup_title_bar()
        self._update_styles()
        self.setup_ui()
        self._theme_connection = qconfig.themeChangedFinished.connect(
            self._update_styles
        )

    def closeEvent(self, event):
        super().closeEvent(event)

    def setup_ui(self):
        layout = QVBoxLayout(self)
        layout.setContentsMargins(20, 40, 20, 20)
```

## 9. 信号与跨面板同步

信号连接、`on_` 前缀、`emit_sync` 防循环、`clear_all(emit_signal=True)` 的规则见《开发规范》§4.3。跨面板同步示例：

```python
def set_image_data(self, pixmap, image, emit_sync=True):
    """接收图片数据；从另一面板同步时 emit_sync=False 防止循环"""
    self.image_canvas.set_image_data(pixmap, image, emit_sync=emit_sync)

# 主窗口连接：色彩 → 明度（反向同理）
color_interface.image_sync_requested.connect(
    lambda p, i: luminance_interface.set_image_data(p, i, emit_sync=False)
)
```

## 10. 自定义控件

自定义控件继承合适的 `QWidget` 子类，重写 `paintEvent` 实现绘制：

```python
class ColorPicker(QWidget):
    """可拖动的圆形取色点"""

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QPainter.RenderHint.Antialiasing)
```

## 11. 右键菜单

用 `RoundMenu` 创建 Fluent 风格菜单，用 `Action` 创建菜单项：

```python
from qfluentwidgets import RoundMenu, Action, FluentIcon

def contextMenuEvent(self, event):
    menu = RoundMenu("")
    menu.addAction(Action(FluentIcon.PHOTO, "更换图片"))
    menu.exec(event.globalPos())
```

## 12. QSplitter

**所有 QSplitter 必须设置 `setHandleWidth(0)` 隐藏分隔条**，保持界面整洁；用 QSplitter 分隔区域可避免窗口压缩时组件重叠。

```python
splitter = QSplitter(Qt.Orientation.Vertical)
splitter.setHandleWidth(0)
splitter.addWidget(upper_widget)
splitter.addWidget(lower_widget)
```

## 13. 禁用 Qt 原生功能

新组件应禁用不符合项目需求的 Qt 原生功能：

|    功能   | 禁用方法                                                       | 适用场景                |
| :-----: | :--------------------------------------------------------- | :------------------ |
| 右键上下文菜单 | `setContextMenuPolicy(Qt.ContextMenuPolicy.NoContextMenu)` | 输入框、标签等不需要原生编辑菜单的控件 |
|  原生工具提示 | 不调用 `setToolTip()`                                      | 使用自定义提示或不需要提示的按钮    |
|  焦点虚线框  | `setFocusPolicy(Qt.FocusPolicy.NoFocus)` 或样式表              | 不需要键盘焦点的装饰性控件       |

需要自定义右键菜单时用 `RoundMenu` 替代，不要启用原生菜单。

## 14. 样式表

避免使用 `!important`：优先用组件特定选择器；必须使用时，确保主题切换后重新应用。
