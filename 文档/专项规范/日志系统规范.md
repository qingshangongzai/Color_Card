# 日志系统规范

> 本文为《开发规范.md》拆分出的专项规范，涉及日志记录、print 禁用审查（code-review 维度 6 第 3 项以本文 §7 为准）时阅读。

## 1. 日志系统概述

项目使用统一的日志系统，用于问题排查、行为追踪、性能监控和运行监控。

**核心组件：**

|          组件         |        文件        | 职责            |
| :-----------------: | :--------------: | :------------ |
|   `LoggerManager`   | `core/logger.py` | 日志管理器，统一配置和控制 |
|    `get_logger()`   | `core/logger.py` | 获取模块级日志记录器    |
| `log_user_action()` | `core/logger.py` | 记录用户操作        |
| `log_performance()` | `core/logger.py` | 记录性能数据        |

## 2. 日志配置

**存储位置：** 日志存储在配置目录下的 `logs/` 子目录，路径：`~/.color_card/logs/`

**文件命名：** 格式 `Color Card_版本号_YYYYMMDD_HHMMSS.log`；每次启动应用创建一个新的日志文件

**清理策略：** 保留最近 30 天的日志文件；启动时自动清理过期日志

## 3. 日志级别定义

|     级别     | 用途      | 示例                   |
| :--------: | :------ | :------------------- |
|   `DEBUG`  | 开发调试信息  | 函数调用、变量值、内部状态        |
|   `INFO`   | 关键操作记录  | 打开图片、提取颜色、保存配置       |
|  `WARNING` | 非致命异常   | 文件不存在但可恢复、配置项缺失使用默认值 |
|  `ERROR`   | 需要关注的问题 | 保存失败、解析错误、服务初始化失败    |
| `CRITICAL` | 致命错误    | 程序无法继续运行             |

## 4. 日志格式

```text
[时间] [级别] [模块名] 消息内容
```

示例：
```text
[2026-02-28 14:30:25] [INFO] [color_service] 提取主色调: 图片=photo.jpg, 颜色数量=5
[2026-02-28 14:30:30] [ERROR] [image_service] 图片加载失败: path=invalid.jpg, error=文件不存在
```

## 5. 使用方法

**模块级日志记录：**

```python
from core import get_logger

logger = get_logger("color_service")

class ColorService:
    def extract_colors(self, image_path: str, count: int = 5):
        logger.info(f"开始提取主色调: path={image_path}")
        try:
            colors = self._do_extract(image_path, count)
            logger.info(f"主色调提取完成: {len(colors)} 个颜色")
            return colors
        except Exception as e:
            logger.error(f"主色调提取失败: {str(e)}")
            raise
```

**用户操作记录：**

```python
from core import log_user_action

log_user_action(action="open_image", params={"path": file_path}, result="success")
```

**性能记录：**

```python
from core import log_performance

with log_performance("generate_scheme", {"type": scheme_type}):
    return _do_generate_scheme(base_hue, scheme_type)
```

## 6. 必须记录的场景

**系统事件：** 程序启动/退出；配置加载/保存；主题切换；语言切换

**用户操作：** 打开/关闭图片；提取颜色；生成配色方案；保存/删除收藏；导入/导出配色

**错误和异常：** 文件操作失败；图片解析错误；配置读写错误；服务初始化失败

## 7. 禁止直接使用 print 输出

**核心原则：禁止在业务代码中直接使用 `print()` 输出调试信息**

**原因：**
- 打包后的应用中，`print()` 输出到 stdout，可能因编码问题导致 `UnicodeEncodeError`
- `print()` 无法分级控制，不利于生产环境调试
- `print()` 输出无法统一收集和管理

**正确做法：**

```python
# 错误用法
print(f"加载完成: {count} 个场景")

# 正确用法
from core import get_logger
logger = get_logger("module_name")
logger.info(f"加载完成: {count} 个场景")
```

**例外情况：**
- 临时调试脚本可以使用 `print()`
- 命令行工具的主程序可以使用 `print()` 输出结果

## 8. AI辅助调试

**日志查看流程：** 应用程序启动失败时，查看控制台输出定位问题；功能执行出现异常时，分析错误信息；结合代码上下文，理解错误原因；根据日志信息制定修复方案。

**日志文件位置：** `~/.color_card/logs/color_card.log`
