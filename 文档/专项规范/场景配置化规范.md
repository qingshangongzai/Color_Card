# 场景配置化规范

> 涉及配色预览、SVG 模板、场景管理功能开发时阅读。

## 1. 概述

配色预览功能采用**纯SVG模板模式**，所有场景统一使用SVG格式，支持内置模板和用户自定义模板。

## 2. 目录结构

**场景数据目录**（`scenes_data/`，打包后只读）：每个场景一个子目录，目录名即场景 id（如 `mobile_ui/`、`web/`），内含 SVG 模板与 `layout.json`；场景类型定义在 `scene_types.json`。

**用户数据存储**：模板路径存于 `~/.color_card/config.json` 的 `scene_templates`，按场景 id 分组。

## 3. 场景类型定义

**scene\_types.json**：定义场景类型，字段为 `id`、`name`、`icon`、`description`、`builtin`、`default`（默认场景）。新增场景类型只改该文件，不在代码里维护类型表。

## 4. 布局配置

**layout.json**：`layout` 下含 `type`（布局类型）、`item_size`（单个模板尺寸）、`spacing`；可选 `scenes` 列表描述该场景下的多个模板（`id`、`name`、`file`、`description`）。

**内置布局类型**：

| 类型ID       | 描述    | 效果             |
| ---------- | ----- | -------------- |
| `single`   | 单图模式  | 一次显示一个，左右切换    |
| `scroll_v` | 垂直滚动  | 多个SVG垂直排列，可滚动  |
| `scroll_h` | 水平滚动  | 多个SVG水平排列，可滚动  |
| `grid_2x2` | 2x2网格 | 4个SVG网格展示      |
| `grid_3x2` | 3x2网格 | 6个SVG网格展示      |
| `mixed`    | 混合布局  | 左侧2x2网格 + 右侧大图 |

## 5. 场景管理

**使用 SceneTypeManager**：

```python
from core import get_scene_type_manager

manager = get_scene_type_manager()
scene_types = manager.get_all_scene_types()
templates = manager.get_all_templates("mobile_ui")
builtin_path = manager.get_builtin_svg_path("mobile_ui")
```

## 6. 用户模板管理

**使用 ConfigManager**：

```python
from core import get_config_manager

config_manager = get_config_manager()
templates = config_manager.get_scene_templates_by_type("mobile_ui")
config_manager.add_scene_template("mobile_ui", {"path": "D:/my_ui.svg", "name": "我的UI模板"})
config_manager.remove_scene_template("mobile_ui", "D:/my_ui.svg")
config_manager.save()
```

## 7. SVG颜色映射

**使用 SVGColorMapper**：

SVG模板使用语义化 `class` 命名规范，支持智能配色映射。

### 7.1 元素分类依据

语义化映射只按 `class` 属性关键词识别元素类型（如 `class="background"` → 背景），不看元素标签。

### 7.2 支持的关键词

| 元素类型 | class 关键词               | 颜色映射   |
| ---- | -------------------------- | ------ |
| 背景   | `background`, `bg`, `back` | 配色\[0] |
| 主元素  | `primary`, `main`          | 配色\[1] |
| 次要元素 | `secondary`, `sub`         | 配色\[2] |
| 强调元素 | `accent`, `highlight`      | 配色\[3] |
| 文字   | `text`, `title`, `label`   | 配色\[4] |
| 描边   | `stroke`, `border`, `line` | 配色\[4] |
| 未识别  | 其他 class 或无 class        | 不映射，保持原色 |

> 文字与描边共用配色[4]；配色少于 5 个时，这两类元素不参与映射，保持原色。

### 7.3 双模式映射策略

系统根据SVG是否有语义化类型信息，自动选择映射模式：

**模式选择逻辑**：

```text
if SVG有语义化类型（存在非UNKNOWN类型的元素）:
    使用语义化映射模式
else:
    使用智能映射模式
```

#### 语义化映射模式

**适用条件**：SVG有语义化类型信息（通过class关键词识别）

**映射规则**：元素类型与配色索引的对应关系同 §7.2；UNKNOWN 不映射，保持原色。

**固定颜色处理**：

- `data-fixed-color="original"`：保持原始颜色
- `data-fixed-color="black"`：固定为黑色

#### 智能映射模式

**适用条件**：SVG无语义化类型信息（所有元素都是UNKNOWN）

**映射规则**：

1. **覆盖检测**：
   - 检测被完全覆盖的元素（后绘制的元素完全覆盖先绘制的元素）
   - 被覆盖的元素标记为 `is_covered=True`，不参与配色映射，保持原始颜色
2. **透明背景处理**：
   - 透明背景视为一个虚拟元素，面积 = 画布面积 - 所有可见元素覆盖的总面积
   - 如果透明背景面积 > 10%（阈值），则视为可见元素，参与配色映射，并添加背景矩形显示对应颜色
   - 如果透明背景面积 <= 10%，则视为被完全覆盖，不参与配色映射，不添加背景矩形
3. **可见元素**（包括有 fill 元素、透明元素和透明背景）：
   - 按面积从大到小排序
   - 从 `colors[0]` 开始顺序映射
4. **不按背景语义特殊处理**：智能映射不识别元素语义；透明区域按上条作为虚拟元素，与普通元素一起按面积排序。

**容器背景**：

- 使用白色作为预览容器背景
- 透明背景由 SVG 内部处理（添加背景矩形）
- 导出时不需要额外添加背景

### 7.4 创建SVG模板规范

1. **画布尺寸**：参考尺寸 400×300（适用于单图、滚动布局）；网格布局可使用较小尺寸（如 200×150）
2. **命名规范**：使用语义化的 `class` 属性；使用描述性的 `id` 属性
3. **颜色填充**：使用任意颜色，系统会自动替换
4. **导出格式**：使用"演示 SVG"或"内联样式"格式，避免外部CSS引用
5. **固定颜色属性**：用 `data-fixed-color` 标记不参与配色映射的元素，取值与效果见 §7.3。

```svg
<svg viewBox="0 0 400 300">
  <rect id="background" class="background" width="400" height="300" fill="#f5f5f5"/>
  <rect id="phone-frame" class="primary" x="120" y="20" width="160" height="260" 
        fill="#1a1a1a" data-fixed-color="original"/>
  <text id="title" class="text" x="200" y="102" fill="#ffffff" 
        data-fixed-color="black">首页</text>
</svg>
```

**使用场景**：

|  场景  | 元素类型 |    推荐属性值   | 说明             |
| :--: | :--: | :--------: | :------------- |
| 手机UI | 手机外框 | `original` | 边框颜色不应随配色变化    |
| 手机UI |  文字  |   `black`  | 文字应始终使用黑色确保可读性 |
|  网页  |  背景  | `original` | 网页场景背景固定为白色    |

## 8. 右键菜单规范

所有 SVG 的右键菜单都包含一个删除项：

- 内置 SVG：点击后提示「内置场景，不可删除」，模板保持不变
- 用户 SVG：点击后执行删除
