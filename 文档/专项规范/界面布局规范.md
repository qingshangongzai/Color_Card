# 界面布局规范

> 本文为《开发规范.md》拆分出的专项规范，涉及界面布局、控件尺寸、防重叠设计时阅读。

## 1. 布局原则

- 使用布局管理器（QVBoxLayout, QHBoxLayout）
- 避免使用固定尺寸，优先使用 size policy

## 2. 防止布局重叠的规范

**问题描述：** 当窗口被压缩时，组件之间可能出现重叠，导致界面显示异常。

**根本原因：** 组件设置了过大的 `minimumSize`；缺少 `sizePolicy` 设置；使用 `setFixedHeight()` 等固定尺寸方法。

**解决方案：**

1. **设置合理的 minimumSize**
   ```python
   self.setMinimumSize(300, 200)  # 根据内容设置合理的最小尺寸
   ```
2. **使用 sizePolicy 控制扩展行为**
   ```python
   self.setSizePolicy(QSizePolicy.Policy.Expanding, QSizePolicy.Policy.Expanding)
   ```
3. **避免使用固定尺寸，使用最小/最大尺寸范围**
   ```python
   self.color_block.setMinimumHeight(40)
   self.color_block.setMaximumHeight(80)
   ```

**实践：** 始终为自定义组件设置 `sizePolicy`；最小尺寸应根据内容实际需求设置；使用 `setMinimumHeight()` 和 `setMaximumHeight()` 组合代替 `setFixedHeight()`。
- 测试时尝试将窗口压缩到最小尺寸，检查是否有重叠

## 4. 网格布局自适应宽度经验

**问题描述：** 当使用 QGridLayout 显示多行色卡，且每行色卡数量不同时，无法实现每行独立占满整行宽度。

**根本原因：** QGridLayout 的所有行共享相同的列宽；不同行的列数不同会导致拉伸效果不一致。

**解决方案：** 改用 **垂直布局 + 水平布局** 的组合方式：

```python
self.cards_layout = QVBoxLayout()
columns = self._calculate_columns(len(colors))

current_row_layout = None
for i, color in enumerate(colors):
    if i % columns == 0:
        current_row_layout = QHBoxLayout()
        self.cards_layout.addLayout(current_row_layout)
    current_row_layout.addWidget(ColorCard(), stretch=1)
```

**决策原则：** 每行列数相同 → 使用 QGridLayout；每行列数不同 → 使用垂直+水平组合布局。
