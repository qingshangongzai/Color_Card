# 基类设计规范

> 本文为《开发规范.md》拆分出的专项规范，涉及画布/卡片/直方图组件开发时阅读。

## 1. 画布基类 (BaseCanvas)

**文件位置：** `ui/canvases.py`

**职责：** 提供图片加载、显示的基础功能；实现坐标转换（画布坐标 ↔ 图片坐标）；管理图片相对坐标系统；提供右键菜单框架。

**子类必须实现的方法：**

```python
def _on_image_loaded(self):
    """图片加载后的处理（子类重写）"""

def _on_image_cleared(self):
    """图片清空后的处理（子类重写）"""

def _draw_overlay(self, painter: QPainter):
    """绘制叠加内容（子类必须实现）"""
    raise NotImplementedError("子类必须实现 _draw_overlay 方法")
```

## 2. 卡片基类 (BaseCard / BaseCardPanel)

**文件位置：** `ui/cards.py`

**职责：** 提供统一的卡片接口；管理卡片列表（BaseCardPanel）；支持批量清空卡片。

**设计原则：** 保持接口简洁（setup_ui, clear）；灵活的卡片创建方法；清晰的职责分离。

## 3. 直方图基类 (BaseHistogram)

**文件位置：** `ui/histograms.py`

**职责：** 提供通用的数据管理（set_data, clear）；提供通用的绘制框架（paintEvent）；定义抽象方法接口。

**子类必须实现的方法：**

```python
def _draw_histogram(self, painter: QPainter):
    """绘制直方图（子类必须实现）"""
    raise NotImplementedError("子类必须实现 _draw_histogram 方法")

def _draw_custom_overlay(self, painter: QPainter):
    """绘制自定义叠加内容（子类重写）"""

def _draw_labels(self, painter: QPainter):
    """绘制标签（子类重写）"""
```

## 4. 基类设计原则

1. **单一职责**：每个基类只负责一类功能
2. **接口清晰**：抽象方法明确，子类职责清晰
3. **可扩展性**：便于添加新的子类实现
4. **代码复用**：提取公共逻辑，消除重复代码
