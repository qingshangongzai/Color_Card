# 基类设计规范

> 涉及画布/卡片/直方图组件开发时阅读。

## 1. 画布基类 (BaseCanvas)

**文件位置：** `ui/canvases.py`

**职责：** 提供图片加载、显示的基础功能；实现坐标转换（画布坐标 ↔ 图片坐标）；管理图片相对坐标系统；提供右键菜单框架。

**必须实现：** `_draw_overlay()`，未实现时抛 `NotImplementedError`。

```python
def _draw_overlay(self, painter: QPainter):
    """绘制叠加内容（子类必须实现）"""
    raise NotImplementedError("子类必须实现 _draw_overlay 方法")
```

**可选重写：** `_on_image_loaded()`、`_on_image_cleared()`。

## 2. 卡片基类 (BaseCard / BaseCardPanel)

**文件位置：** `ui/cards.py`

**职责：** 提供统一的卡片接口；管理卡片列表（BaseCardPanel）；支持批量清空卡片。

**必须实现：** `BaseCard.setup_ui()`、`BaseCard.clear()`；`BaseCardPanel._create_card(index)`，未实现时抛 `NotImplementedError`。

## 3. 直方图基类 (BaseHistogram)

**文件位置：** `ui/histograms.py`

**职责：** 提供通用的数据管理（set_data, clear）；提供通用的绘制框架（paintEvent）；定义抽象方法接口。

**必须实现：** `_draw_histogram()`，未实现时抛 `NotImplementedError`。

```python
def _draw_histogram(self, painter: QPainter):
    """绘制直方图（子类必须实现）"""
    raise NotImplementedError("子类必须实现 _draw_histogram 方法")
```

**可选重写：** `_draw_custom_overlay()`、`_draw_labels()`。
