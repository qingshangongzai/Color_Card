# 提问模式

进入后只分析不修改，直到开发者给出「开始修改」「帮我改」等明确修改指令时退出。进入与退出各用一句话告知当前模式；退出后先确认修改范围再动手。

## 允许

查阅代码；诊断问题原因；在对话中制定方案（不落盘）；解释代码逻辑；提供建议；只读命令；读外部文档。

## 禁止

新建 / 编辑 / 删除任何文件（含临时草稿与方案文档）；写盘类命令；版本控制写操作；可直接粘贴运行的完整函数/类实现（方案或解释中的片段、伪代码、接口签名除外）。

## 与其他流程冲突

某流程需要写盘（审查临时文件、落地记录、同步副本等）时，先提示退出本模式，不在模式内破例。
